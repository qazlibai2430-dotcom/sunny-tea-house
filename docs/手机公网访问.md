# 手机公网访问

本轮目标是让顾客通过 HTTPS 链接直接打开交互界面，不需要安装 App、连接同一 Wi-Fi，或保持店家的电脑开机。

## 当前发布内容

- 发布在 Sites 静态托管上，访问权限为公开，拿到链接即可访问。
- 保留五种界面语言与五种评价语言、标签选择、示例生成、编辑、复制和平台跳转。
- 公网演示不调用 DeepSeek，也不发送企业微信通知。页面明确显示“演示体验”。
- 所有演示交互在浏览器中完成，不访问 `127.0.0.1`。
- Google 商家链接仍未配置；小红书打开官方入口，由用户自行粘贴和发布。

## 手机使用

1. 在手机浏览器打开发布后的 HTTPS 链接。
2. 选择语言、感受标签和平台，点击生成。
3. 修改文案，核对后勾选确认，再复制。
4. 如果手机浏览器限制自动复制或弹窗，使用文本框长按复制及页面的手动平台链接。

页面采用标准网页技术，面向当前 iOS Safari、Android Chrome、鸿蒙等系统的现代浏览器。不能保证已停止维护的旧浏览器或所有第三方内置浏览器行为完全一致。不同地区网络也可能影响访问，最终需要用实际手机与网络打开链接确认。

## 后续修改与接入

桌面项目目录保持不变。`npm.cmd run build` 构建本地后端版本；`npm.cmd run build:public` 构建公网演示版本到 `public-dist`。`src/api.js` 隔离两种模式；`shared/review-demo.js` 是共享示例模板。

后续修改源码并重新发布后，使用同一个网站地址。真实 AI 接入需要把后端部署到公网或适配托管服务端，设置服务端密钥与费用限制；不要在公开网页中填写密钥。

本轮不购买域名。后续如需要品牌域名，可另行绑定；不影响当前链接体验。
